<h2 id="levelojs">2. Levelo.js Framework</h2>

**Levelo.js** is a lightweight, high-performance frontend JavaScript framework built completely from scratch by **MD Saiful Alom Siam**.

<h3 id="levelojs-architecture">Architectural Highlights</h3>

* **NoVDOM (No Virtual DOM):** Operating on a **NoVDOM** architecture, Levelo.js bypasses expensive Virtual DOM diffing algorithms to ensure memory-efficient and fast UI updates.
* **Single Page Application (SPA):** Engineered specifically to build fluid, client-side SPAs with zero lag.
* **React-like DX with Solid.js Philosophy:**
  * **Familiar API:** The developer experience (DX) feels as intuitive and ergonomic as React.
  * **Reactive Engine:** Incorporates fine-grained reactivity concepts inspired by Solid.js.
  * **100% Custom Codebase:** Despite drawing conceptual inspiration from these ecosystems, **not a single line of code is copied**. The architecture and internal engine are built entirely from scratch.

<h2 id="kivex">3. Kivex — Kinetic Vector Exchange</h2>

**Kivex** is an advanced, unified icon ecosystem designed to maintain consistent iconography across multiple frontend platforms and mobile frameworks. 

Maintained by MD Saiful Alom Siam with contributions from open-source developers, Kivex currently features **300+ custom vector icons** crafted directly by Siam.

<h3 id="kivex-packages">Official Kivex Packages</h3>

Kivex allows teams to use a single design language across web, mobile, and native apps through its 8 tailored packages:

1. **kivex-icons** — Core JavaScript implementation (Built & Maintained by Siam)
2. **kivex-levelo** — Native icon binding for Levelo.js (Built & Maintained by Siam)
3. **kivex-react** — Official React integration (Built & Maintained by Siam)
4. **kivex-solid** — Solid.js wrapper (Built by Community Contributors)
5. **kivex-svelte** — Svelte integration (Built by Community Contributors)
6. **kivex-vue** — Vue.js package (Built by Community Contributors)
7. **kivex-react-native** — Cross-platform React Native package (Built by Community Contributors)
8. **kivex_flutter** — Native Flutter package (Built by Community Contributors)

Since **NGCBD** is an official initiative operated under the Motion Mind ecosystem, Motion Mind actively rewards developers who test, adopt, and build with its tools.

<h3 id="bonus-rules">How the Bonus Works</h3>

If you build and submit your project using Motion Mind DevTools, you receive an automatic **5% Marks Bonus** added directly to your project's total score.

* **Levelo.js Integration:** Using Levelo.js as your project's primary frontend framework.
