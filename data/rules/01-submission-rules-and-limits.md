<h1 id="submission-overview">Submission Rules & Project Limits</h1>

Understand the core guidelines for project submissions, repository requirements, and participation limits for each bi-monthly league cycle at NGCBD.

---

<h2 id="league-structure">1. The Bi-Monthly Showcase Model</h2>

To maintain our **Zero Pressure Philosophy**, NGCBD operates on a 2-month cycle model instead of high-stress weekly sprints or rigid hackathons.

<h3 id="showcase-rules">Cycle Participation Rules</h3>

* **Maximum Project Limit:** A developer can submit a maximum of **2 Projects per 2-Month Cycle** (evaluated at 100 Marks each).
* **Flexible Submissions:** You can submit either 1 project or 2 projects during the 2-month window based on your availability and project scope.
* **Single Submission Alternative:** Submitting a single, highly complex, and deeply researched project is fully supported. Quality and technical depth are prioritized over volume.

---

<h2 id="repository-requirements">2. Repository & Live Demo Requirements</h2>

Every project submitted to the NGCBD Showcase must meet baseline open-source standards to be eligible for peer code review and score evaluation.

<h3 id="mandatory-deliverables">Mandatory Submission Criteria</h3>

* **Public GitHub Repository:** Your source code must be hosted on a public GitHub repository with an active, progressive commit history (bulk/single-commit uploads are flagged for review).
* **Standard Documentation:** The repository must include a clear `README.md` file explaining the problem solved, tech stack, setup instructions, and system architecture.
* **Working Live Demo or Build Link:** A valid, accessible live URL (Vercel, Netlify, Render, GitHub Pages) or clean build/run instructions for local testing must be provided.
* **Original Work:** Submissions must be original. Direct tutorial clones, boilerplate forks without significant additions, or copied repositories will be disqualified under our integrity guidelines.

---

<h2 id="submission-lifecycle">3. Submission Lifecycle & Deadlines</h2>

<h3 id="stage-breakdown">Submission Workflow</h3>

1. **Submission Portal Open:** Developers submit their GitHub repository and live demo link via the official NGCBD portal at any point during the active cycle.
2. **Review Window:** Evaluators and peer community members inspect the codebase, test the live deployment, and run code architecture analysis.
3. **Score & Feedback Publication:** Detailed review notes, category marks, and badges are published at the close of the bi-monthly cycle.
