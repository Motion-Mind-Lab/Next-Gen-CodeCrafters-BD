<h1 id="evaluation-overview">250-Mark Evaluation System</h1>

Learn how project submissions, community activities, and ecosystem integrations are scored under the standard 250-Mark evaluation framework at NGCBD.

---

<h2 id="scoring-breakdown">1. Overall 250-Mark Breakdown</h2>

The standard competition framework operates on a **250-Mark Base Evaluation** system across two project submissions and active community engagement.

<h3 id="mark-distribution">Score Allocation</h3>

* **Project Submissions (Up to 200 Marks):** Evaluation of up to 2 submitted projects (scored at up to 100 Marks each).
* **Community & Engagement (Up to 50 Marks):** Score earned through peer code reviews, creating technical GitHub issues, and constructive community discussions.

<p style="font-family: monospace; font-size: 0.8rem; background: #FAFAFC; padding: 10px 14px; border: 1px solid #E2E8F0; border-radius: 6px; color: #0F172A;">
  <strong>Base Score (250 Max)</strong> = Project 1 (100) + Project 2 (100) + Community Activity (50)
</p>

---

<h2 id="project-rubric">2. 100-Mark Project Evaluation Rubric</h2>

Each submitted project is evaluated out of 100 points based on five core engineering pillars:

<h3 id="rubric-table">Evaluation Criteria</h3>

| Criteria | Marks | Key Focus Areas |
| :--- | :---: | :--- |
| **Code Architecture & Cleanliness** | **30 Marks** | Code organization, folder structure, modularity, performance optimization, low memory footprint, and bug minimization. |
| **Originality & Problem Solving** | **25 Marks** | Uniqueness of the project idea, depth of custom logic, and real-world problem-solving impact (avoiding basic tutorial clones). |
| **UI/UX & Responsive Design** | **20 Marks** | Visual polish, user experience flow, mobile/desktop responsiveness, smooth interaction states, and accessibility standards. |
| **Documentation & Setup Ease** | **15 Marks** | Quality of the repository `README.md`, setup instructions, architecture breakdown, and working live demo links. |
| **Engineering Complexity** | **10 Marks** | Effective tech stack utilization, API integrations, state management depth, and handling of edge cases. |

<h2 id="ecosystem-bonus-rules">3. The 5% Score Bonus Hack</h2>

The Motion Mind Ecosystem Bonus is a strategic leaderboard lever designed to give builders a competitive edge in final rankings.

<h3 id="bonus-mechanics">How the Bonus Impacts Rankings</h3>

* **5% Equivalent Value:** Integrating Motion Mind DevTools (Levelo.js or Kivex) awards up to an additional **12.5 Bonus Marks** (5% of the 250 total base).
* **Rank Booster & Tie-Breaker:** The bonus acts as a game-changer when leaderboard scores are tight. For example, if a developer is in 3rd place with 215 marks, applying the 12.5 ecosystem bonus boosts their tally to **227.5 marks**—instantly vaulting them past competitors into 1st place!
* **Ecosystem Integration:** Bonus points are automatically calculated during code review upon verification of Levelo.js core framework usage or Kivex package integration in the submitted codebase.
